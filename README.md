# Сервис обмена одеждой «Круговорот вещей»

## Описание проекта

«Круговорот вещей» — сервис для обмена одеждой, который помогает находить новые вещи и продлевать срок их использования.

Проект разрабатывается в рамках дисциплины «Технологии разработки приложений на базе фреймворков».

## Технологии

- Python
- Django
- SQLite
- SQL
- HTML / CSS / JavaScript
- JSON
- pytest / flake8

## Структура проекта

- `clothing_exchange/` — настройки Django и корневые URL-маршруты.
- `items/` — приложение для отображения каталога вещей, поиска и статистики.
- `items/views.py` — представления страниц и получение данных из SQLite через ORM-подобные запросы.
- `items/urls.py` — именованные URL-маршруты приложения.
- `items/templates/` — HTML-шаблоны страниц.
- `items/static/` — стили, JavaScript и изображения.
- `models/` — классы предметной области (из предыдущих этапов).
- `data/` — исходные данные в формате JSON.
- `db/` — модуль работы с базой данных (`database.py`).
- `db.sqlite3` — файл базы данных проекта (в корне).
- `sql/schema.sql` — SQL-скрипт создания структуры таблиц.
- `sql/queries.sql` — примеры SQL-запросов для предметной области.
- `tests/` — автоматические тесты проекта.

## Работа с базой данных

В проект подключена SQLite для хранения информации о вещах, пользователях и заявках на обмен.

База данных содержит три таблицы:
- `items` — информация о вещах;
- `users` — информация о пользователях;
- `exchanges` — заявки на обмен.

Для организации связей используются первичные и внешние ключи. Таблица `exchanges` связана с таблицами `items` и `users`.

Создание структуры базы данных выполняется с помощью файла `sql/schema.sql`.
Для переноса исходных данных из JSON в SQLite используется скрипт в `db/database.py`. Повторный запуск переноса не создаёт дубликаты существующих записей (используется `INSERT OR IGNORE`).

## SQL-запросы

В файле `sql/queries.sql` представлены проверенные запросы для работы с базой данных:
- получение списков объектов;
- фильтрация по доступности, размеру и состоянию (`WHERE`);
- поиск по названию (`LIKE`);
- подсчёт общего количества вещей (`COUNT`);
- объединение таблиц для получения связанных данных (`JOIN`);
- группировка и статистика (`GROUP BY`, `HAVING`).

## Интеграция SQLite с Django

Для получения данных используется модуль `sqlite3` с настройкой `row_factory = sqlite3.Row`, что позволяет обращаться к полям результата по именам (как к словарю).

Реализованы следующие пользовательские сценарии:
1. **Главная страница**: отображает только доступные для обмена вещи, отсортированные по названию.
2. **Карточка вещи**: детальная информация о вещи и поиск похожих вещей того же размера.
3. **Поиск вещей**: параметризованный SQL-запрос с `LIKE ?` для безопасного поиска по названию.
4. **Статистика**: агрегированный запрос с `GROUP BY` для подсчета количества вещей у каждого владельца.

## Шаблоны Django

Для формирования HTML-страниц используется Django Template Language (DTL):
- наследование шаблонов (`{% extends %}`) и блоки (`{% block %}`);
- подключение повторяющихся элементов (`{% include %}`);
- передача данных через контекст представления;
- циклы и условия (`{% for %}`, `{% if %}`, `{% empty %}`);
- именованные маршруты (`{% url %}`);
- подключение статических файлов (`{% static %}`).
