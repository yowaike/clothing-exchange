# Сервис обмена одеждой

## Описание проекта

Сервис предназначен для обмена одеждой между пользователями.
Пользователь может добавить вещь, доступную для обмена, и отправить
или получить запрос на обмен.

## Целевая аудитория

Люди, которые хотят обмениваться одеждой с другими пользователями
и находить вещи, подходящие для обмена.

## Предметная область

Основными объектами системы являются:

- **Пользователь** — участник сервиса.
- **Вещь** — одежда, которую пользователь предлагает для обмена.
- **Запрос** — предложение обменять одну вещь на другую.
- **Передача** — согласованный обмен вещами между пользователями.

## Основные функции

- добавление вещи для обмена;
- поиск вещи по названию;
- фильтрация вещей по размеру;
- сортировка вещей;
- проверка доступности вещи;
- создание запроса на обмен;
- отмена запроса;
- добавление пользователя;
- сохранение и загрузка данных в JSON.

## Основные классы

- `Item` — вещь, доступная для обмена. Атрибуты: `id`, `owner_name`,
  `item_name`, `size`, `condition`, `is_available`. Методы:
  `is_suitable_for_exchange()`, `__str__()`, `from_data()`, `to_data()`.
- `User` — пользователь сервиса. Атрибуты: `id`, `name`, `email`.
  Методы: `__str__()`, `from_data()`, `to_data()`.
- `ExchangeRequest` — запрос на обмен. Атрибуты: `id`, `item`, `requester`,
  `status`. Методы: `cancel()`, `get_status_text()`, `__str__()`,
  `from_data()`, `to_data()`.

Запрос хранит ссылки на объект вещи и объект пользователя, а при сохранении
в JSON превращает их в идентификаторы.

### Назначение модулей

- `main.py` — точка входа, меню программы.
- `models/items.py` — класс `Item` и функции для работы с вещами.
- `models/users.py` — класс `User` и функции для работы с пользователями.
- `models/exchanges.py` — класс `ExchangeRequest` и функции для работы
  с запросами на обмен.
- `storage.py` — загрузка и сохранение данных в JSON с преобразованием
  между словарями и объектами.
- `utils.py` — вспомогательные функции ввода.
- `data/` — JSON-файлы с данными.
- `tests/` — автоматические тесты.
