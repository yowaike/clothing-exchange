# Сервис обмена одеждой «Круговорот вещей»

## Описание проекта

«Круговорот вещей» — сервис для обмена одеждой, который помогает находить новые вещи и продлевать срок их использования.

Проект разрабатывается в рамках дисциплины «Технологии разработки приложений на базе фреймворков».

## Технологии

- Python
- Django
- HTML
- CSS
- JavaScript
- JSON
- pytest
- flake8

## Структура проекта

- `clothing_exchange/` — настройки Django и корневые URL-маршруты.
- `items/` — приложение для отображения каталога вещей.
- `items/views.py` — представление главной страницы и подготовка данных.
- `items/urls.py` — именованные URL-маршруты приложения.
- `items/templates/items/base.html` — базовый HTML-шаблон.
- `items/templates/items/home.html` — шаблон главной страницы.
- `items/templates/items/includes/item_card.html` — переиспользуемый шаблон карточки вещи.
- `items/static/items/style.css` — стили веб-интерфейса.
- `items/static/items/main.js` — JavaScript для взаимодействия с каталогом.
- `items/static/items/images/clothing.jpg` — изображение для главной страницы.
- `data/items.json` — данные о вещах в формате JSON.
- `storage.py` — загрузка данных из JSON-файла.
- `tests/` — автоматические тесты проекта.

## Шаблоны Django

Для формирования HTML-страниц используется Django Template Language (DTL).

В проекте реализованы следующие возможности:

- **Наследование шаблонов:** `home.html` наследует базовый шаблон `base.html` с помощью `{% extends %}`.
- **Блоки:** `{% block %}` позволяет задавать заголовок страницы и её содержимое.
- **Подключение шаблонов:** `{% include %}` используется для повторного использования разметки карточки вещи.
- **Контекст:** представление передаёт список вещей в шаблон.
- **Циклы и условия:** `{% for %}`, `{% empty %}` и `{% if %}` используются для отображения каталога и обработки пустого списка.
- **Именованные маршруты:** ссылки формируются с помощью `{% url 'items:home' %}`.
- **Фильтры:** `upper` и `capfirst` используются для форматирования текста.
- **Статические файлы:** `{% load static %}` и `{% static %}` используются для подключения CSS, JavaScript и изображения.

## Работа с данными

На текущем этапе сведения о вещах хранятся в JSON-файле и загружаются с помощью `storage.py`. На главной странице отображаются вещи, доступные для обмена.

Django ORM, регистрация и авторизация пользователей, а также формы обмена пока не реализованы. Работа с базой данных и дальнейшее развитие функциональности относятся к следующим этапам проекта.

## Установка и запуск

Создайте виртуальное окружение и установите зависимости из `requirements.txt`.

Активируйте виртуальное окружение и выполните команды из корневой папки проекта.

Проверка конфигурации Django:

```powershell
python manage.py check
```

Запуск веб-приложения:

```powershell
python manage.py runserver
```

После запуска откройте в браузере адрес `http://127.0.0.1:8000/`.

## Запуск тестов

```powershell
python -m pytest -v
```

## Проверка качества кода

```powershell
python -m flake8 . --extend-exclude=venv,.venv
```
